# Sorting Algorithms in C

This project demonstrates two basic sorting algorithms in C using a menu-driven program.

## Features

- Takes array input from the user
- Performs Insertion Sort or Selection Sort
- Displays the array after each iteration
- Prints the final sorted array
- Beginner-friendly implementation

## Algorithms Implemented

- Insertion Sort
- Selection Sort

## Concepts Used

- Arrays
- Functions
- Loops
- Conditional Statements
- Sorting Algorithms

## Language

- C

## How to Run

1. Compile the program using any C compiler.
2. Run the executable.
3. Enter 5 array elements.
4. Choose:
   - `1` for Insertion Sort
   - `2` for Selection Sort
5. View the array after each iteration and the final sorted array.

## Expected Output

### Input

```text
Enter 5 elements of the array:
5
2
4
1
3

Choose Sorting Method:
1. Insertion Sort
2. Selection Sort
Enter your choice: 1
```

### Output

```text
Your array is:
5    2    4    1    3

Array after 1 iteration of Insertion Sort:
2    5    4    1    3

Array after 2 iteration of Insertion Sort:
2    4    5    1    3

Array after 3 iteration of Insertion Sort:
1    2    4    5    3

Array after 4 iteration of Insertion Sort:
1    2    3    4    5

Sorted Array:
1    2    3    4    5
```

## Purpose

This project was developed as a college practical to understand the working of Insertion Sort and Selection Sort. It displays each iteration of the sorting process, making it easier for beginners to visualize how the algorithms work.
